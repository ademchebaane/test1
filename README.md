# Tunisian Algorithm Studio

A flat, GitHub-ready web app for Tunisian high-school algorithmique.

## What is included

- French/Tunisian-style pseudo-code compiler + interpreter.
- Syntax diagnostics with line/column information.
- Integer, real, boolean, string and 1-based array variables.
- `Si`, `SinonSi`, `Sinon`, `Pour`, `TantQue`, `Répéter`, `Lire`, `Ecrire` and `EcrireL`.
- `DIV`, `MOD`, comparisons, boolean operators and built-in math helpers.
- Interactive debugger: Step, Continue, Stop, breakpoints, variables, execution stack and trace.
- Installable web-app metadata for browser/PWA environments.
- Capacitor Android configuration.
- GitHub Actions workflow that builds a debug APK from this flat repository.

## Repository shape

Keep all application source files at repository root. `android/` is generated by Capacitor in CI, so you do not need to commit the generated Android project.

```text
TunisianAlgorithmStudio/
├─ .github/workflows/android.yml
├─ app.js
├─ compiler.js
├─ styles.css
├─ index.html
├─ manifest.webmanifest
├─ service-worker.js
├─ capacitor.config.ts
├─ package.json
└─ README.md
```

## Web

```bash
npm install
npm run dev
```

For production:

```bash
npm run build
```

Deploy the generated `dist/` directory to GitHub Pages or another static host.

## Android APK locally

You need Node.js, Java 21+ and Android Studio/SDK installed.

```bash
npm install
npm run android:add
npm run android:sync
npx cap open android
```

Then build the debug APK from Android Studio.

## GitHub Actions APK

Push the repository to GitHub. The workflow in `.github/workflows/android.yml` installs dependencies, creates the Capacitor Android project, builds the web app, syncs it into Android, and assembles the debug APK. The APK is uploaded as a workflow artifact named `tunisian-algorithm-studio-debug-apk`.

## Notes on syntax

The parser is designed around the common French/Tunisian lycée conventions rather than any single teacher's formatting. For example:

```text
Algorithme Exemple
Variables
  n, i : Entier
  somme : Entier
Debut
  Lire(n)
  somme := 0
  Pour i de 1 à n Faire
    somme := somme + i
  FinPour
  EcrireL("Somme = ", somme)
Fin
```

The project avoids `eval()` for algorithm expressions. Programs are parsed into a small AST and executed by the runtime, which makes debugger state deterministic and keeps the editor isolated from arbitrary JavaScript execution.
